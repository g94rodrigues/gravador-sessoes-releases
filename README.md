# Gravador de Sessões: instalador

Aqui ficam só os instaladores do Gravador de Sessões. O código não fica neste repositório.

Para instalar, baixe `GravadorDeSessoes-win-Setup.exe` em [Releases](../../releases/latest) e abra. O Windows avisa que o instalador não é assinado: clique em **Mais informações** e depois em **Executar assim mesmo**. Depois da primeira instalação, o app se atualiza sozinho a partir daqui.

O app grava e transcreve tudo no próprio computador. Nada das sessões passa por este repositório.
